# Request Tracker Changelog

## [1.1.0.0] - 2026-04-07

### Added
- **2 entities** with **82+ fields** supporting lightweight request intake and tracking:
  - Request (primary tracking record with 62 fields) for submission through completion lifecycle
  - Request Type (20 fields) for classification, routing rules, and workflow configuration
- **1 choice set** (Request Type Category with 14 values) for classifying requests including information requests, data requests, access requests, technical support, leadership taskings, and general assistance
- Comprehensive tracking for submission details, assignment, review, approval workflow, response/resolution tracking, and satisfaction feedback
- Support for both internal and external requests with contact management, security classification, and visibility controls

### Changed
- Initial baseline release for lightweight cross-organizational request tracking
