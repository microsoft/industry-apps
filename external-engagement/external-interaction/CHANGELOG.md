# External Interaction Changelog

## Unreleased

## [1.1.0.0] - 2026-04-28

### Added

#### Custom Tables
- **External Interaction**: Core table for tracking external communications including inquiries, requests, complaints, feedback, reports, applications, and referrals
- **External Interaction Source**: Reference table for communication channels (Phone, Email, Web Form, Social Media, In-Person, Mail)
- **External Interaction Topic**: Subject matter categorization for routing and reporting
- **Country**: Geographic reference table for countries
- **State or Province**: First-level administrative divisions within countries

#### Choice Fields
- **External Interaction Type**: 8-value choice field (Inquiry, Request, Complaint, Feedback, Report, Application/Submission, Referral, Other)

#### User Interface
- Model-Driven App: Configured External Interaction application with navigation and forms
- Forms: Configured baseline forms for all entities
- Views: Configured baseline views for all entities  

#### Sample Data
- Created sample data for all External Interaction entities to support testing and demonstration
